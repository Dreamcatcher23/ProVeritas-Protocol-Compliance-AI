# Fixes Applied - Dashboard and Download Issues

## Date: March 9, 2026

## Issues Fixed

### Issue 1: Dashboard Not Loading Protocols ✅

**Problem:**
```
Protocol fetch error: An error occurred (ValidationException) when calling the Query operation: 
The table does not have the specified index: user_id-timestamp-index
```

**Root Cause:**
The `protocol_audit` DynamoDB table doesn't have a Global Secondary Index (GSI) named `user_id-timestamp-index`.

**Solution:**
Changed from using `query()` with GSI to using `scan()` with FilterExpression:

```python
# Before (using query with index)
response = audit_table.query(
    IndexName='user_id-timestamp-index',
    KeyConditionExpression='user_id = :uid',
    ExpressionAttributeValues={':uid': user_id},
    ScanIndexForward=False,
    Limit=50
)

# After (using scan with filter)
response = audit_table.scan(
    FilterExpression='user_id = :uid',
    ExpressionAttributeValues={':uid': user_id},
    Limit=50
)
```

**Result:** Dashboard now successfully loads all protocols for the logged-in user.

### Issue 2: Download Reports Not Working ✅

**Problem 1: Wrong File Formats**
- UI showed PDF, DOCX, and JSON download buttons
- S3 only contains JSON and TXT files
- PDF and DOCX downloads returned 404 errors

**Problem 2: Windows Path Issue**
```
Download error: [Errno 2] No such file or directory: '/tmp/PROTO-xxx_report.json'
```

**Root Cause:**
1. Report generator Lambda only creates `.json` and `.txt` files, not PDF or DOCX
2. Code used Unix path `/tmp/` which doesn't exist on Windows

**Solution:**

1. **Updated results.html** - Show only available formats:
```html
<!-- Before: 3 buttons (PDF, DOCX, JSON) -->
<!-- After: 2 buttons (JSON, TXT) -->
<button onclick="downloadReport('json')">Download JSON</button>
<button onclick="downloadReport('txt')">Download TXT</button>
```

2. **Fixed Windows temp directory** in app.py:
```python
# Before (Unix-only)
temp_file = f"/tmp/{protocol_id}_report.{format}"

# After (Cross-platform)
import tempfile
temp_dir = tempfile.gettempdir()
temp_file = os.path.join(temp_dir, f"{protocol_id}_report.{format}")
```

**Result:** 
- Downloads now work correctly on Windows
- Only shows formats that actually exist in S3
- Files download successfully to browser

## Known Limitations

1. **Dashboard Performance:**
